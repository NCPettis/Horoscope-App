# ♈️ My MAYA Horoscope-App


## Project Description

A horoscope app that gives you a fitting Maya Angelou quote based on your birthday. 

## Tech Stack

- **HTML** 
- **CSS**
- **JavaScript**

## How to Run or View It

1. Clone or download the repository.
2. Open `index.html` in a browser or serve the project using a local development server.
3. Input your date of birth
4. Click **Find Out**
5. A horoscope quote will display
